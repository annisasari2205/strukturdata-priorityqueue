# 🏥 Sistem Antrean Puskesmas

Aplikasi Sistem Antrean Puskesmas berbasis **Python dan Streamlit** yang menerapkan konsep **Priority Queue** untuk mengatur antrean pasien berdasarkan tingkat prioritas.

## Fitur

* Pendaftaran pasien
* Nomor antrean otomatis
* Lihat daftar antrean
* Panggil pasien
* Priority Queue:

  1. Darurat
  2. Lansia
  3. Ibu Hamil
  4. Umum

## Teknologi

* Python
* Streamlit
* Queue (Deque)

## Menjalankan Program

```bash
pip install streamlit
streamlit run app.py
```

## Struktur Data

Program menggunakan **Priority Queue**, sehingga pasien dengan prioritas lebih tinggi akan dipanggil terlebih dahulu.
